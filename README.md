# AppleO

TypeScript/Next.js AI analytics dashboard with chat, prediction forms, reports, authentication, and visualization components.

## What It Does

- Provides dashboard and analytics UI components.
- Includes AI chat and prediction form experiments.
- Supports login/auth context and report generation flows.
- Organizes reusable UI components for a richer product surface.

## Tech

TypeScript, Next.js/React, dashboard UI, AI chat, analytics workflows.

## Repository Map

- `AIChat.tsx` - AI assistant/chat interface.
- `Dashboard.tsx`, `AdvancedAnalytics.tsx` - analytics views.
- `PredictionForm.tsx`, `ReportGenerator.tsx` - ML/product workflow components.
- `AuthContext.tsx`, `Login.tsx`, `api.ts` - auth and API wiring.

## Status

Prototype frontend. It is strongest as a UI/product engineering sample.
